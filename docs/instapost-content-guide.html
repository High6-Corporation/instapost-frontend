InstaPost Website — Content Editing Guide

A step-by-step guide for updating the homepage. No technical knowledge required.

Before You Begin

What you need

  • Your WordPress login (the admin link and your username/password). If you don't have these, ask your developer.

Key terms used in this guide

TermWhat it means
FieldA box where you type content (e.g. a heading or description).
SectionOne block of the homepage (e.g. the Hero, the Testimonials).
Row / CardA repeated item inside a section (e.g. one testimonial, one industry).
Add Row / + buttonAdds another card/item to a list.
Minus / × buttonRemoves that card/item.
Publish / UpdateThe button that saves your changes and makes them live.
Bold (B)The B button that makes selected text stand out.

Golden Rules

  1. Always click "Update" (top-right) when you finish. Changes are not saved — and not visible on the site — until you do.
  2. Don't paste from Word or Google Docs directly if the text looks strange. Use Paste as plain text (right-click → Paste as plain text, or Ctrl/Cmd + Shift + V), then re-apply bold.
  3. To make text stand out, select it first, then click the B (Bold) button. In some sections, bold text automatically appears in the brand colour — you don't need to change any colour setting.
  4. Leave a field empty only if you're sure it should be blank. Empty optional fields fall back to a default.
  5. Icons and images should come from your developer for a consistent look (see the Switch to InstaPost section).

How to Open the Homepage Editor

  1. Log in to the WordPress admin.
  2. In the left menu, click Pages.
  3. Find Home in the list and click to edit it.
  4. Scroll down to reach the Dynamic Content (Homepage) area — this holds all the sections below, in order.

1. Hero Section

The big headline and intro text at the very top of the homepage.

How to edit

  1. Find Hero Section.
  2. Edit the Main Heading (the large title).
  3. Edit the Subtext (the line below the title).
  4. Click Update.

2. ROAS Archive Section

The section that highlights a key result / achievement.

How to edit

  1. Find ROAS Archive Section.
  2. Edit the Main Heading and Subtext.
  3. Under Bottom Summary, edit:
    • Title
    • Description
    • Result Label (what the number measures)
    • Result Value (the number itself)
  4. Click Update.

3. Clients (Logos & Case-Study Cards)

Used by the ROAS Archive and Proof sections to show client brands like "ABC-CBN", "Dermacare", etc.

How to edit an existing client

  1. In the left menu, click Clients.
  2. Click the client you want to change.
  3. Update the details and any other fields shown on the page.
  4. Click Update.

How to add a new client

  1. Click Clients in the left menu.
  2. Click Add New.
  3. Fill in the client details.
  4. Scroll down and complete the remaining fields that appear on the site.
  5. Add the link (where the card should lead when clicked).
  6. Click Publish.

4. Switch to InstaPost Section

"Why move to InstaPost" — a heading, a subtext, and up to 4 cards.

How to edit the heading and text

  1. Find Switch to InstaPost Section.
  2. Edit the Main Heading and Subtext.

How to edit the 4 cards

e.g. "Returns you can measure", "Social-first speed", "One team for everything", "KOLs on call in 24 hours".

  1. Each card has a Card Icon, Card Title, and Card Description. Edit what you need.
  2. To add a card: click Add Row, then fill in the new fields.
  3. To remove a card: click the minus (×) button on that card.
Note on icons: For a consistent look, request icons from your developer rather than uploading your own.

How to edit the Stat Badges

The small highlight labels, e.g. "Target ROAS 10x".

  1. Click inside the Stat Badges field.
  2. To add a badge: press Enter to start a new line, then type the new badge.
  3. To make a value stand out (it will show in the brand colour): select just the number/text and click the B (Bold) button.

When you're done, click Update.

5. Proof Section

The "results / case studies" area with a button.

How to edit

  1. Find Proof Section.
  2. Edit the Main Heading and Subtext.
  3. Edit the button link ("View all case studies"): the label (button text), the URL (destination), and the target (whether it opens in a new tab).
  4. Click Update.

6. Performance Package Section

The performance-package callout with its button.

How to edit

  1. Find Performance Package Section.
  2. Edit the Pre-header (small label above the title), the Main Heading, and the Subtext.
  3. Edit the link (button text, URL, and target).
  4. Click Update.

7. Built for Brands Section

Lists the industries InstaPost works with.

How to edit the main text

  1. Find Built for Brands Section.
  2. Edit the Main Heading and Subtext.

How to add / edit industries

  1. Each industry has an Industry Name and Industry Description.
  2. To add one: click Add Row and fill in the empty fields.
  3. To remove one: click the minus (×) button.

How to edit the closing line (with bold)

  1. Find the footer text field (e.g. "…and ambitious SMEs ready to market…").
  2. Replace the text, then select the word you want to emphasise and click B (Bold).

When you're done, click Update.

8. How We Work Section

The step-by-step process list.

How to edit the main text

  1. Find How We Work Section.
  2. Edit the Main Heading and Subtext.

How to add / edit steps

  1. Each step has a Step Title and Step Description.
  2. To add a step: click Add Row and fill in the fields.
  3. To remove a step: click the minus (×) button.
The step numbers like "1.", "2." are added automatically — you don't need to type them.

How to edit the note box at the bottom

  1. Replace the text.
  2. Select the word you want to emphasise and click B (Bold).

When you're done, click Update.

9. InstaPost Guarantee Section

The guarantee promise block.

How to edit

  1. Find InstaPost Guarantee Section.
  2. Edit the Pre-header, Main Heading, and Subtext.
  3. Click Update.

10. Testimonial Section

Video testimonials from clients ("In their words").

How to edit the main text

  1. Find Testimonial Section.
  2. Edit the Main Heading and Subtext.

How to add / edit a testimonial

  1. Each testimonial has:
    • Brand Name — the company (e.g. "Razon's by Glenn").
    • Client Name — the person (e.g. "Glenn Carraeon").
    • Position — their role (e.g. "Owner & CEO").
    • Video — upload the video file.
    • Custom Thumbnail (optional) — see the note below.
  2. To add one: click Add Row and fill in the fields.
  3. To remove one: click the minus (×) button.
About the thumbnail: The Custom Thumbnail is optional. If you leave it empty, the site automatically uses the first frame of the video as the preview. Upload a custom thumbnail only when you want full control over exactly what the preview image looks like.

When you're done, click Update.

11. CTA Section

The final "Ready for returns you can measure?" call-to-action.

How to edit

  1. Find CTA Section.
  2. Edit the Main Heading and Subtext.
  3. Click Update.

Quick Troubleshooting

ProblemWhat to do
My changes aren't showing on the site.You didn't click Update. Open the page again and click it.
The text looks weird / has strange spacing.You pasted from another program. Re-paste using Paste as plain text, then re-apply bold.
Bold didn't turn the brand colour.Make sure you selected the text first, then clicked B.
A card / step is missing.Check that its fields aren't empty, and that you saved.
The icon looks off / inconsistent.Ask your developer for the correct icon file.
