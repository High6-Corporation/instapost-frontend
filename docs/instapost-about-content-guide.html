InstaPost About Page — Content Editing Guide

A step-by-step guide for updating the About page. No technical knowledge required.

Before You Begin

What you need

  • Your WordPress login (the admin link and your username/password). If you don't have these, ask your developer.

Key terms used in this guide

TermWhat it means
FieldA box where you type content (e.g. a heading or description).
SectionOne block of the About page (e.g. the Hero, the Founders).
Row / CardA repeated item inside a section (e.g. one value, one founder, one stat).
Add Row / + buttonAdds another card/item to a list.
Minus / × buttonRemoves that card/item.
UpdateThe button that saves your changes and makes them live.
Bold (B)The B button that makes selected text stand out.

Golden Rules

  1. Always click "Update" (top-right) when you finish. Changes are not saved — and not visible on the site — until you do.
  2. Don't paste from Word or Google Docs directly if the text looks strange. Use Paste as plain text (right-click → Paste as plain text, or Ctrl/Cmd + Shift + V), then re-apply bold.
  3. To make text stand out, select it first, then click the B (Bold) button. On the About page, bold text automatically appears in the brand colour — yellow in the Hero and red in most other sections. You never set a colour by hand.
  4. Leave a field empty only if you're sure it should be blank. Empty optional fields fall back to a default.
  5. The bold names in each step below match the field labels in the editor. If one reads slightly differently, it's the same field.

How to Open the About Page Editor

  1. Log in to the WordPress admin.
  2. In the left menu, click Pages.
  3. Find About Us in the list and click to edit it.
  4. Scroll down to reach the Dynamic Content (About Us) area — this holds all the sections below, in order.

1. Hero Section

The large title over the team photo at the very top of the About page.

How to edit

  1. Find Hero Section.
  2. Edit the Pre-Header — the small yellow label above the title (e.g. "About Insta Post"). Leave it empty to keep the default label.
  3. Edit the Main Heading (the big title). To make part of it yellow, select that text and click B (Bold). To put words on their own line, press Enter.
  4. Edit the Subtext (the paragraph under the title).
  5. Click the Background Image to upload or replace the team photo.
  6. Click Update.

2. Introduction Section

An intro block with a heading, a paragraph, and a photo.

How to edit

  1. Find Introduction Section.
  2. Edit the Main Heading and Subtext.
  3. Click the Introduction Image to upload or replace the photo.
  4. Click Update.
The "Inquire Now" button and where it links are fixed by the developer and can't be changed from these fields.

3. Fullwidth Video Section

One video that spans the full width of the page, with a play button in the middle.

How to change the video

  1. Find Fullwidth Video Section.
  2. Remove the current file with the minus (×) button, then upload the new video.
  3. Click Update.
This holds one video only — there are no rows to add. The clip starts muted and visitors turn the sound on using the player controls. Both .mp4 and .webm work. Right now a placeholder file (sample.mp4) is loaded until the real clip is supplied.

4. Mission & Vision Section

A photo beside two red cards — the Mission and the Vision.

How to edit

  1. Find Mission And Vision Section.
  2. Click the Mission And Vision Image to change the photo.
  3. Under Mission Contents, edit the Mission Title and Mission Paragraph.
  4. Under Vision Contents, edit the Vision Title and Vision Paragraph.
  5. Click Update.
Only the first Mission row and the first Vision row are shown. Keep just one row in each.

5. Why We Exist Section

The long-form story text with a highlighted pull-quote.

How to edit

  1. Find Why We Exist Section.
  2. Edit the Pre-Header (small label) and Main Heading.
  3. Edit the Body Content (the main paragraphs). Bold turns words red.
  4. Edit the Highlight Quote — the large italic pull-quote in the middle.
  5. Edit the Footer Content (the closing paragraphs). Bold turns words red.
  6. Click Update.

6. Our Promise Section

The red block of numbered promises with the founders' signatures.

How to edit the labels

  1. Find Our Promise Section.
  2. Edit Pre-Header Left (top-left label) and Pre-Header Right (top-right label).

How to add / edit the promises

  1. Under Promise List, each row has one Item Text.
  2. To add a promise: click Add Row. To remove: click the minus (×) button.
The numbers "1.", "2.", "3." are added automatically — don't type them.

How to edit the signatures

  1. Under Signature List, each row has a Name and a Position.
  2. Add or remove rows the same way.

When you're done, click Update.

7. What We Stand Section

"What we stand for" — the list of company values.

How to edit the main text

  1. Find What We Stand Section.
  2. Edit the Main Heading and Subtext.

How to add / edit values

  1. Each value has a Value Title and a Value Description.
  2. To add one: click Add Row. To remove: click the minus (×) button.

When you're done, click Update.

8. Stats Section

The row of headline numbers (e.g. "5 — Years, founder-led", "100+ — Filipino brands served").

How to edit

  1. Find Stats Section.
  2. Under Stats List, each row has a Stat Value (the number) and a Subtext (the label under it).
  3. To add a stat: click Add Row. To remove: click the minus (×) button.
  4. Click Update.
This looks best with 4 stats. The numbers show in brand red automatically.

9. Founders Section

The founder cards (photo, name, role, bio) and a closing note.

How to edit the main text

  1. Find Founders Section.
  2. Edit the Main Heading and Subtext.

How to add / edit a founder

  1. Under Founders List, each row has:
    • Profile — the founder's photo.
    • Name
    • Position — their role (shows in red).
    • Description — their short bio.
  2. To add a founder: click Add Row. To remove: click the minus (×) button.
If a founder has no photo, the card shows their initials in a circle instead.

How to edit the closing note

  1. Find Footer Note and replace the text.
  2. Select the word you want to emphasise and click B (Bold).

When you're done, click Update.

10. Empowering Section

The gold "where this is going" statement with a button.

How to edit

  1. Find Empowering Section.
  2. Edit the Pre-Header (small red label), the Main Heading, and the Subtext. In the heading, Bold turns words red.
  3. Edit the Redirection Link: the URL (destination), the Title (button text), and the Target (whether it opens in a new tab).
  4. Click Update.
If you leave the link Title empty, the button shows the default "We're hiring — join the team".
About the final CTA on the About page: the red "Let's Build Your Social Media Presence" block at the bottom is a shared, fixed banner — it can't be edited from the About page fields yet. Ask your developer to change its wording.

Quick Troubleshooting

ProblemWhat to do
My changes aren't showing on the site.You didn't click Update. Open the page again and click it.
The text looks weird / has strange spacing.You pasted from another program. Re-paste using Paste as plain text, then re-apply bold.
Bold didn't turn the brand colour.Make sure you selected the text first, then clicked B.
A row / card is missing.Check that its fields aren't empty, and that you saved.
I edited the bottom CTA but nothing changed.That final call-to-action is a fixed shared banner and can't be edited from the page fields yet — contact your developer.
